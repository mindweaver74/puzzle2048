# 🔢 숫자 합치기

> 같은 숫자 타일을 합쳐 2048을 만들어라! 단순하지만 끝없이 빠져드는 네온 감성 숫자 퍼즐.

**▶ 지금 바로 플레이** → [https://mindweaver74.github.io/puzzle2048](https://mindweaver74.github.io/puzzle2048)

---

## 🎮 게임 방법

1. 4×4 격자판에 숫자 타일이 놓여 있습니다
2. 상하좌우로 **스와이프(또는 방향키)**하면 모든 타일이 그 방향으로 이동합니다
3. 같은 숫자 타일 둘이 만나면 **합쳐져서 2배**가 됩니다 (2+2=4, 4+4=8…)
4. 이동할 때마다 빈 칸에 2 또는 4 타일이 새로 등장합니다
5. **2048** 타일을 만들면 승리! 더 이상 움직일 수 없으면 게임 오버

## ✨ 주요 특징

- 🌈 **네온 타일** — 숫자별 고유 색상 (2=파랑 → 2048=황금)
- 💥 **합치기 이펙트** — 합칠 때 파티클 폭발 + 팝 애니메이션
- 🔥 **콤보 보너스** — 한 번 이동에 여러 개 합치면 콤보 카운트
- 💾 **이어하기** — 게임 종료 후 이어서 플레이 가능
- 🏆 **최고 점수** — 로컬에 저장, 도전 기록 유지
- 🎵 **효과음** — 숫자별 음정이 다른 합치기 사운드
- 🎉 **2048 달성 연출** — 황금 폭죽 파티클 + 축하 화면

## 💡 전략 팁

- 큰 숫자를 **한쪽 모서리**에 모아두는 것이 핵심 전략입니다
- 가장 큰 타일이 있는 방향으로는 거의 이동하지 마세요
- 한 번 이동에 여러 개를 합치면 **콤보 보너스** 점수를 받을 수 있어요
